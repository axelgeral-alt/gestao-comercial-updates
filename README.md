# Gestão Comercial — canal público de atualizações

Este repositório é dedicado à distribuição pública dos instaladores do Portal de Encomendas (PE) e da Gestão Comercial V7 (GC/V7).

- Os binários são publicados em GitHub Releases, não no histórico normal de código.
- Cada artefacto é verificado por tamanho e SHA-256 antes da publicação.
- Não incluir código-fonte das aplicações, dados de clientes, bases de dados, credenciais ou cópias de segurança.
- A transição mantém os manifestos Supabase existentes como ponte até a nova origem de atualização ser validada em Windows e Android.

Os releases identificam explicitamente as aplicações, versões e builds abrangidos.
